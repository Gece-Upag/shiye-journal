前置条件

手机与电脑处于同一局域网（同 WiFi，或手机开热点让电脑接入）。

1. 电脑端：让本地模型服务能被局域网访问

① 修改服务监听地址：监听 0.0.0.0（默认仅 127.0.0.1 本机可访问）
   · Ollama：添加系统环境变量 OLLAMA_HOST=0.0.0.0，然后完全退出并重启 Ollama
   · LM Studio / llama.cpp：在服务设置里把监听地址改为 0.0.0.0

② Windows 防火墙：新建「TCP 入站规则」放行对应端口（Ollama 默认 11434）
   建议勾选：域、专用；不勾选公用

③ 获取电脑的局域网 IPv4：cmd 里执行 ipconfig，复制当前网卡的 IPv4 地址

④ 验证服务：在电脑浏览器访问 http://<IPv4>:端口/api/version
   返回一段 JSON 就说明服务正常了

⑤ 提前拉取 / 加载目标模型，并记下准确的模型名称

2. 手机端：在拾页里连上它

① 在 AI 辅助里新建或编辑一套配置，模式选「本地模型」
② API 地址填 http://<电脑IPv4>:端口/v1
   （例如 http://192.168.1.23:11434/v1）
③ 填入模型名称，要和电脑上 ollama list 显示的一致
④ 请求超时建议 ≥ 60 秒（首次加载模型要好几十秒）
⑤ 点「测试连接」，连通后保存即可使用

连不上时按这个顺序排查

· 手机和电脑真的在同一个网络里吗？（手机开热点让电脑连，也是可以的）
· 电脑上 Ollama 是不是设了 OLLAMA_HOST=0.0.0.0 并重启过？
· 防火墙有没有放行这个端口？
· 地址里的 IP 是不是电脑当前的局域网 IP？（换 Wi-Fi 后 IP 可能变了）
· 用电脑浏览器打开 http://<IPv4>:端口/api/version 能通吗？
  电脑上都通不了，那就是服务端的问题，先解决它
